## Filming Guide

### Equipment (Minimum Viable)
- **Phone 1:** Run the app (the "actor" phone)
- **Phone 2:** Film phone 1's screen from over-shoulder angle
- Screen recording built into iOS/Android for clean captures
- Natural lighting (outdoors at a pitch is ideal)
- No microphone needed for short-form (captions only)
- Basic mic for YouTube tutorials (wired earbuds are fine)

### Screen Recording Tips
- Use the app with real player names and photos (looks authentic)
- Pre-populate 12-15 players so lists look full
- Set up a draft that's ready to start before hitting record
- For the raffle animation: record the whole thing uncut — it's 12 seconds of pure gold
- For draft picks: speed up 2x in editing (keeps it snappy)

### Caption/Subtitle Rules
- **All** short-form: burned-in captions, always
- White text, black outline, centered bottom third
- Font: bold, sans-serif (match your brand — Montserrat Black)
- Keep captions to 4-6 words per frame
- YouTube long-form: use YouTube's auto-caption + manual chapter markers

### Editing
- **Short-form:** CapCut (free, has all trending templates)
- **YouTube:** DaVinci Resolve (free) or CapCut desktop
- **Landing hero:** After Effects or CapCut for clean transitions
- Add your purple brand color (#7C3AED) as a consistent accent

## Embedding on Landing Page

### Technical Implementation
The hero video (#1) should be embedded as:
```html
<video autoplay muted loop playsinline poster="/assets/video-poster.jpg">
  <source src="/assets/hero-demo.webm" type="video/webm">
  <source src="/assets/hero-demo.mp4" type="video/mp4">
</video>
```

- `autoplay muted loop playsinline` — silent background loop
- `poster` — first frame as image for instant display
- WebM first (smaller), MP4 fallback
- Host on CDN (Cloudflare, Bunny) or keep in `public/assets/` if under 5MB
- Lazy-load if below the fold

### YouTube Embeds (for tutorial section)
If adding a "How It Works" section on landing with the full tutorial:
```html
<lite-youtube videoid="YOUR_ID"></lite-youtube>
```
Use `lite-youtube-embed` npm package — loads 10x faster than standard YouTube iframe.
